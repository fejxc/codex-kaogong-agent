# 母题补充层（讲题沉淀协议）

本目录是**母题卡库的生长层**：exam-research 的 95 张母题卡是离线统计生成的静态源（软链接挂载，勿改）；讲题和复盘产出的新变体沉淀在这里，与源分离。

## 定位

- 上游：`~/Downloads/exam-research/knowledge/母题卡/`（静态，重建会覆盖）
- 本层：`data/复盘引擎/母题补充/<主考点>.md`（动态，随做题生长，随私有仓库备份）
- 消费：`考我`/`复习` 出题时，检索顺序为 总题库（`题库/`）→ 本层 → 全量池（`exam-research-pool.jsonl`）

## 写入门槛（与 xingce Skill 写回门禁一致）

1. 只有完整讲解已完成、且题目来源明确（题库 qid / 用户提供并核验）时才写入。
2. 一题一条，不虚构真题；原创变式必须标 `原创变式`，不得标真题来源。
3. 用户答对且无新变体特征的普通讲题不写（避免把本层变成流水账）。

## 条目格式

文件按主考点命名，如 `类比推理-逻辑_场所与活动.md`。每条：

```markdown
### YYYY-MM-DD ｜ qid 或 原创变式标识 ｜ 一句话变体特征

- 母题卡：类比推理-逻辑_场所与活动（对应上游卡名）
- 变体特征：二级辨析落在"主体是否为职业"（区别于卡内示例的场所维度）
- 题目：工人：工厂：工作（如为题库题给 qid，不整段复制题面）
- 关联：错因卡 event_id（如有）／用户当时的错因标签
- 状态：已核验（来源核验）／待确认
```

## 幂等

同一 qid 同一变体特征只保留一条；重复讲同一题时更新日期与关联，不新增条目。
