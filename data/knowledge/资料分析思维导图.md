## 思维导图

### 〇、材料阅读与做题流程（前置能力，暂无 index 节点）

- **材料类型**
  - 文字型
  - 表格型
  - 图表型：柱状图、折线图、饼图
  - 综合型（文字+图表组合）
- **做题流程**：先读问题 → 带问题回材料定位 → 判断所求量（题型识别）→ 列式 → 速算 → 按选项差距定精度
- **四大常见陷阱**
  - 时间陷阱：同比 vs 环比、累计 vs 当期、年份区间端点
  - 单位陷阱：万/亿、%/‰、千克/吨
  - 口径陷阱：部分与整体统计范围不一致（如产量 vs 销量）
  - 概念陷阱：是 n 倍/多 n 倍、百分数/百分点

### 一、四大核心量：现期、基期、增长量、增长率

#### 1. 现期量与基期量 【DA-01｜方法卡：基期量(high)、现期量(medium)】

- 术语定位：同比 = 上年同期；环比 = 上一统计周期；先定位再选 r 的方向
- **基期量三公式**
  - 基期 = 现期 − 增长量
  - 基期 = 增长量 ÷ 增长率
  - 基期 = 现期 ÷ (1 + r)（r 带符号；"下降 d%"时分母写 1 − d）
- 小 r 化除为乘：A/(1+r) ≈ A×(1−r)；前提 |r| 小、误差明显小于选项差距、不会跨选项分界
- 基期和差：A/(1+a) ± B/(1+b)；分母差距大时不可用现期和差代替基期和差
- 与比重结合：分清部分/整体各自的现期与增长率，不混用
- **现期量（预测类）**
  - 保持增长量不变：未来 = 现期 + n × 每期增长量（线性）
  - 保持增长率不变：未来 = 基期 × (1+r)^n（指数）
  - 追赶/达到 n 倍：先写目标式 A ≥ nB（"超过"用严格大于），再求年数；整除情形"首次超过"要多加一期
  - 名义与实际增长率：(1+名义) = (1+实际) × (1+CPI)；物价上涨时名义 > 实际

#### 2. 增长量 【DA-02-AMOUNT｜方法卡：增长量(high)】

- 基本式：增长量 = 现期 − 基期 = 现期/(1+r) × r
- **百化分**：r = 1/N 时，增长量 = 现期/(N+1)；减少量 = 现期/(N−1)
- 近似：增长量 ≈ 现期 × r，误差量级 ≈ 现期 × r²/(1+r)；靠近选项分界时必须用百化分或精算
- 平均增长量 = (现期 − 基期) ÷ 年份差；年份差按时间轴间隔数（2016—2020 年差为 4）
- 指定增长量判断："增长量大于 X" ⇔ 现期 > 基期 + X；图表题看柱间高度差
- **增长量比较**
  - 均为正增长：现期大且 r 大 → 增长量大（单调性）
  - 现期与 r 一大小：百化分或代入公式
  - 含负增长：不套用正增长口诀，统一比较带符号增长量
- 多项增长：总体 = 各部分增长量之和，有升有降先抵消
- 增长贡献率 = 部分增长量 / 总体增长量；拉动率 = 部分增长量 / 总体基期（两个分母不同，易混）

#### 3. 增长率 【DA-02-RATE｜方法卡：一般增长率(high)】

- 公式：增长率 = 增长量/基期 = 现期/基期 − 1（可正可负）
- **概念辨析**
  - 百分数表示比例；百分点表示百分数的变化量（降 5 个百分点 ≠ 降 5%）
  - 是 n 倍 ⇔ 增长率 = n − 1；增长 n 倍 ⇔ 增长率 = n
  - 降幅扩大/收窄：先把"下降"当负增长，再比较绝对值变化
- 给百分点还原另一期增长率：先判方向，再加减
- **增长率比较**：统一化为同一形式再比——现期/基期（倍数大者大）或 增长量/基期；不能只比增长量

### 二、增长率进阶题型

#### 4. 间隔（隔年）增长 【暂无 index 节点｜方法卡：间隔增长率(high)】

- 核心式：**R = r1 + r2 + r1 × r2**；乘积项取舍由选项差距决定，选项接近时必须保留
- 间隔倍数：是 n 倍 = R + 1；多 n 倍 = R
- 间隔基期 = 现期/(1+R)；间隔增长量：先求 R 再百化分
- 逆向求某期：r2 = (R − r1)/(1 + r1)；R > r1 时 r2 为正
- 边界：三期及以上不能套两期公式，按各期增长系数连乘

#### 5. 年均增长 【DA-06｜方法卡：年均增长率(high)】

- 年均增长量 = (现期 − 基期) ÷ 年份差
- 年均增长率：(1+r)^n = 现期/基期（复利，不是总增长率÷年数）
- 比较：年份差相同 → 直接比 现期/基期；年份差不同 → 归一为 (现期/基期)^(1/n) 再比
- 小 r 近似：r ≈ 总增长率/n，**系统性偏大**，只能当上界缩小范围；选项接近时用平方/立方表精算
- 大 r：用平方、立方、四次方表反推（11²=121 … 20²=400；1.2³≈1.7、1.3³≈2.2、1.4³≈2.7）
- 年份差按间隔数：2018→2023 年份差为 5

#### 6. 混合增长率 【暂无 index 节点｜方法卡：混合增长率(high)】

- 适用：整体 = 部分 + 部分（进出口=进口+出口、全国=城镇+农村、全年=1-11月+12月、A+非A）
- **范围规律**：min(部分 r) ≤ R ≤ max(部分 r)；等号边界是某部分基期为 0 或两部分 r 相等
- **偏向规律**：R 靠近基期量更大一方（权重是基期量，不是现期量；只靠范围不能定相近选项）
- 加权公式：R = (A·ra + B·rb)/(A+B)；反推规模比 A/B = (rb − R)/(R − ra)
- 线段法（盐水思想）：距离与基期量权重成反比
- 差值转化：顺差=出口−进口 → 出口=进口+顺差

#### 7. 乘积增长率 【暂无 index 节点｜方法卡：乘积增长率(high)】

- 适用：A = B × C（总额=单价×数量、产量=单产×面积、部分=总体×比重）
- **rA = b + c + b × c**；两因子增长率都不小时乘积项不可省
- 一因子不变（增长率为 0）时，总量增长率 = 另一因子增长率
- 可反推：已知总量增长率与一个因子增长率，求另一因子
- 与相加结构（混合增长率）、相除结构（平均数增长率）区分

### 三、比例关系三大件：比重、平均数、倍数

#### 8. 比重 【DA-03｜方法卡：比重(high)】

- 现期比重 = 部分/整体（必须同口径）；"X 占 Y"中 X 部分、Y 整体
- **基期比重 = A/B × (1+b)/(1+a)**（A、B 为现期值；a = 部分增长率，b = 整体增长率，勿放反）
- **两期比重比较（升降判断）**：只比 a 与 b——a>b 升、a<b 降、a=b 不变，无需算出比重
- **两期比重差 = A/B × (a−b)/(1+a)**；结果带符号，单位是百分点
- 相关指标：增长贡献率（分母=总体增长量）、产销率 = 销量/产量
- 饼图角度/面积只作辅助，不能替代计算；各部分比重之和应为 1（验算）

#### 9. 平均数 【DA-04｜方法卡：平均数(high)】

- 识别词：均、每、人均、单位面积、单位产量；"每 X 的 Y"中 X 是分母、Y 是分子
- 现期平均数 = 分子/分母，直接计算或分数比较
- 基期平均数 = A/B × (1+b)/(1+a)（a = 分子增长率，b = 分母增长率）
- 两期平均数比较：a>b 升、a<b 降（与比重同构）
- 两期平均数差 = A/B × (a−b)/(1+a)
- **平均数增长率 = (a − b)/(1 + b)**（注意分母是 1+b，与两期差公式不同）
- 平均数倍数：(A/B) ÷ (C/D) = (A·D)/(B·C)，先约分
- 中位数（排序取中间，偶数个取中间两项平均）、众数（出现最多）

#### 10. 倍数与比例 【DA-05｜方法卡：倍数与比例(medium)】

- 语言翻译：是 n 倍 ⇔ A/B = n；多 n 倍 ⇔ A/B − 1 = n；超过 n 倍 ⇔ A > n×B
- 现期倍数直接 A/B，"多几倍"最后减 1
- 平均数倍数：先约分再算，避免分子分母颠倒取成倒数
- 混合比例（盐水思想）：总体比例落在两比例之间、偏向规模大的一方；线段距离反推规模比
- 权重口径：比例混合取部分规模；增长率混合取基期量——两类不要互串

### 四、速算与比较工具

#### 11. 速算技巧 【DA-09】

- **截位直除**：选项差距大 → 截前两位；差距小 → 截前三位
- **特征数字（百化分）**：25%=1/4、33.3%≈1/3、16.7%≈1/6、14.3%≈1/7、12.5%=1/8、11.1%≈1/9、9.1%≈1/11 等
- 化除为乘（小 r 求基期，见分支 1）
- 错位加减法
- 增长量近似 现期×r 的误差控制（见分支 2）
- 通用前提：估算误差明显小于选项有效差距；结果靠近选项分界必须精算

#### 12. 分数比较 【DA-07】

- 直除看首位（商几）
- 交叉相乘（分子交叉比较）
- 分子分母同向变化：分子增速大 → 分数变大
- 增长率比较、比重比较、平均数比较最终都落到分数比较

#### 13. 综合分析（综合判断题）【DA-08】

- 题型：四个选项逐项判断"正确/错误/有几个正确"
- 常见设错：偷换时间/单位/口径、无中生有、混同比环比、把比重差说成比重、把增长最快说成增长最多
- 策略：先做易验证项（直接查找/口算项），难算项最后；每项独立核验再选

### 五、考试应用要点（kaogong 教学建议，非官方）

- 先看问题再读材料，带着目标找数
- 先建立稳定正确率，再提速；每篇材料约 5–6 分钟为教学参考值，按实际卷面调整
- 做完用"反向验证"自检：基期×(1+r)=现期、各部分比重和=1、贡献率之和=1 等
