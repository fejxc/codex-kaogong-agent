# Codex 公考智能备考 Agent

这个工作区把两个经审查的 Agent Skills 接入 Codex，并使用本地 Markdown/JSON 保存知识目录、错题关联与复习状态。粉笔仍是学习主线；在尚未导入你的粉笔讲义和课程目录前，基础考点均标作“暂定”。

## 开始使用

在此项目目录打开 Codex。项目 Skills 位于 `.agents/skills/`；创建完成后请新开一个 Codex 任务或重启/刷新客户端，让技能索引重新加载。之后直接用自然语言即可，例如：

- “按粉笔方法讲这道资料分析题，只讲解，先别记错题。”
- “我选 C，正确答案是 A；我当时把两期比重和现期比重混了。帮我复盘并安排一道变式。”
- “我刚学完粉笔两期比重。按讲义整理条件、公式和易错点，关联历史错题。”
- “我今天做了浙江事业编职测，按模块记下套题成绩。”
- “根据本周本地记录写周报；只报告确实保存的数据。”
- “把目标考试切换为 2027 江西省考。”

### Skills

- `.agents/skills/xingce-review-pro/`：行测讲解、复盘、错因卡、弱点档案和幂等复习写回；保留 GPL-3.0-only 许可证及 NOTICE。
- `.agents/skills/kaogong/`：申论、综应、职测、公基和考试规划；保留 MIT 许可证。
- 可选参考上游朱批录 `kaogong-study-tracker` 的日报字段；它不随本仓库打包，项目日报写入器不依赖它，也不调用其非幂等计数脚本。
- 花生十三：只作补充参考。审查发现其仓库没有独立 LICENSE 文件，故未复制其技能或资料。

项目级路由、答案核验和写回约束见 [AGENTS.md](AGENTS.md)。第三方仓库的版本、许可、风险、更新和验证记录见 [技能审查报告](docs/第三方技能审查.md)。

## 学习数据保存位置

- 个人目标与进度：`data/profile.md`（初始为空白画像）。
- 考试元数据目录：`data/exams/catalog.json`。
- 粉笔优先的暂定知识树与关系：`data/knowledge/index.json`、`data/knowledge/relations.json`。
- 经核验导入的自有题目：`data/questions/`。
- 行测错因卡、弱点和复习历史：`data/复盘引擎/`，由 xingce Skill 的写回工具负责。
- 套题/每日汇总：`data/tracker/daily/YYYY-MM-DD.json`；每日来源记录是汇总统计唯一依据。朱批录的 `wrong_questions.json` 与 `stats_cache.json` 不参与本项目的单题错因或统计。

`data/` 下的个人档案、题目、截图、日报和错题均由 `.gitignore` 排除，避免误提交。当前没有导入旧数据，空记录不代表已经学习或完成复习。

## 日常操作

- **添加错题**：给题目、自己的答案、标准答案/来源和解题过程；确认要复盘后，Skill 核验并在满足门禁时写入 `data/复盘引擎/`。原因不清楚时只标“待确认”。
- **添加粉笔知识点**：提供课程截图、目录、讲义或笔记，并注明课程/章节；确认识别结果后再更新知识节点、别名和来源。模糊截图中的数字要先核对。
- **复习或查弱点**：说“考我”“复习我的两期比重错题”或“查最近重复错因”。优先用已核验原题或明确标注的原创变式。
- **切换目标考试**：给出考试 ID/地区/年份和已知科目、试卷类别；未见公告时不替事业编猜分类。
- **日报/周报**：要求“按本地记录汇总”。若没有记录，回答暂无数据；不得把单题卡片与套题汇总再相加。

日报采用朱批录本地 JSON 的字段思路，事件由 `scripts/record_daily.py` 按 `event_id` 幂等更新；具体规则见 [学习记录约定](data/reviews/README.md)。系统会为相同日期、考试、来源和分模块成绩生成稳定键；独立复练应提供不同批次名。

如需使用朱批录的其他功能，可按[上游仓库说明](https://github.com/KaguraNanaga/kaogong-study-tracker)单独安装到自己的 Codex 用户技能目录；本项目的日报记录和统计不要求安装该 Skill。

## 更新第三方 Skills

不要执行上游安装脚本。按审查报告记下的仓库和版本重新克隆到临时目录，阅读 README、SKILL.md、LICENSE/NOTICE、安装脚本和写入代码；在临时克隆内运行其验证工具与测试，再把经审查的 Skill 目录及许可证更新到 `.agents/skills/`。更新后在新 Codex 任务中验证触发与路由。所有个人状态保留在 `data/`，不得复制进 Skill 包。
